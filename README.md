# NYC-Collision-Analysis-Sql-Powerbi
End-to-end data analytics project using MS SQL Server and Power BI to analyze over 2M New York City collision records.

## Project Overview
This project analyzes more than 2 million New York City motor vehicle collision records using Microsoft SQL Server and Power BI.

The objective is to identify:
* Collision trends over time
* Geographic hotspots
* High-risk hours
* Injury & fatality patterns
* Major contributing factors

The project demonstrates an end-to-end data analytics workflow consisting of:
* Data Cleaning
* SQL Analysis
* Data Modeling
* Dashboard Development
* Insight Generation

*The analysis was completed as my Bachelor's capstone project in Computer Science (Database specialization).*

## Dataset
* **Source:** NYPD Motor Vehicle Collisions
* **Size:** More than 2 million records
* **Contains:** Crash dates, locations, boroughs, vehicle types, injuries, fatalities, and contributing factors.

---

## Data Cleaning
The project performs several preprocessing tasks including:
* ✔ Missing value handling
* ✔ Duplicate removal
* ✔ Date & Time conversion
* ✔ Text standardization
* ✔ Invalid coordinate filtering
* ✔ Index optimization

These transformations prepare the dataset for efficient querying and visualization.

## SQL Analysis
Key analyses include:
* Collision trends by year
* Borough comparison
* Peak crash hours
* Weekday vs Weekend analysis

## Key Findings
* **Brooklyn and Queens** recorded the highest number of collisions.
* **Evening rush hour (4–7 PM)** showed the highest collision frequency.
* **Driver inattention/distraction** was the leading contributing factor.
* **Staten Island** had comparatively fewer crashes but a higher fatality rate per crash.
